# Telegram-бот з меню та запитом до AI

Навчальний проєкт на JavaScript (Node.js). Бот має чотири розділи меню: «Студент», «IT-технології», «Контакти» та «Prompt AI». Для генерації відповідей використовується Groq API.

## 1. Що потрібно

- Node.js 20 або новіший
- Telegram-акаунт
- Токен бота від `@BotFather`
- API-ключ Groq

## 2. Налаштування Telegram-бота

1. Відкрийте Telegram і знайдіть `@BotFather`.
2. Надішліть команду `/newbot`.
3. Вкажіть назву та username бота.
4. Скопіюйте токен, який видасть BotFather.

## 3. Отримання Groq API key

1. Відкрийте https://console.groq.com/keys
2. Увійдіть або створіть обліковий запис.
3. Створіть API key і скопіюйте його. Не публікуйте цей ключ.

## 4. Запуск локально

У папці проєкту виконайте:

```bash
npm install
```

Скопіюйте `.env.example` у файл `.env` та заповніть значення:

```env
BOT_TOKEN=токен_від_BotFather
GROQ_API_KEY=ключ_Groq
STUDENT_SURNAME=Ваше прізвище
STUDENT_GROUP=Ваша група
CONTACT_PHONE=Ваш номер телефону
CONTACT_EMAIL=your.email@example.com
```

Запустіть бота:

```bash
npm start
```

Відкрийте свого бота в Telegram і натисніть `/start`.

## 5. Деплой на Railway

1. Завантажте проєкт у власний GitHub-репозиторій. Не додавайте `.env` до репозиторію.
2. Відкрийте https://railway.app/ і створіть новий проєкт із GitHub-репозиторію.
3. У налаштуваннях сервісу додайте змінні середовища `BOT_TOKEN`, `GROQ_API_KEY`, `STUDENT_SURNAME`, `STUDENT_GROUP`, `CONTACT_PHONE`, `CONTACT_EMAIL`.
4. Команда запуску: `npm start`.
5. Переконайтеся, що сервіс запустився та в логах є `Telegram bot is running.`

Для бота використовується long polling, тому окремий HTTP-сервер або домен не потрібні. На хостингу має працювати постійний сервіс/worker, який не засинає.

## 6. Перевірка функцій

- `/start` — привітання та показ головного меню.
- «Студент» — показує прізвище та групу.
- «IT-технології» — показує короткий опис технологій.
- «Контакти» — показує телефон та e-mail.
- «Prompt AI» — переводить бота в режим очікування запиту та надсилає його до Groq API.
- `/menu` — повертає головне меню.

## 8. Примітки

- Персональні дані студента та контакти заповнюються через `.env`.
- `.env` і токени не можна завантажувати в публічний репозиторій.
- Якщо AI не відповідає, перевірте правильність `GROQ_API_KEY`, доступність API та логи хостингу.
